# 地图、场景与模型

这是站内界面的操作参考。先观察实际页面；收费、权限和 Key 处理遵循技能主文件。文中的填写 Key 由用户自行完成。

## 地图拼接

把场景图扩展、拼接成更大的地图。

入口：首页「地图拼接」；快捷键 M。

使用条件：工具 + AI。编辑与 AI 生成分开；调用生成能力时检查 Key 和消耗。

准备：准备起始图片或之前保存的地图状态。非本站或 Banana 生成的图片可能有分辨率偏差，导致无法扩展；想复用自有图片，请先在自由生图上传为参考图，重新生成 16:9 或 1:1 的 4K 图片。

1. 从首页「地图拼接」进入，或在首页按 M。导入起始图片；已有地图状态时加载状态继续编辑，先核对图片尺寸与当前图块。
2. 需要 AI 扩展时，打开地图拼接的「设置」，点击「读取全局 API」，将主站配置读入当前工具。
3. 尚未配置全局 API 时，先回首页点击顶部「API 设置」，填入完整 Key 并选择对应模式；代充 Key 选择「代充」。返回地图拼接，再次点击「读取全局 API」。
4. 确认扩展方向、图块安排及上下、左右重叠方式。先做一个相邻图块，提示词固定视角、地面类型、建筑比例与光照方向。
5. 生成或导入相邻图块后，放大查看道路、墙面、水岸和阴影的交界。接缝不自然时先修正这一块，再继续扩大地图，避免错误扩散到更多图块。
6. 每完成一段地图就保存状态，便于继续编辑；需要最终图片时导出地图。图片导出与可编辑状态分别保留，下载后检查文件是否完整。

输出：拼接地图与可继续编辑的状态。

注意：拼接已有图片与调用 AI 生成是两件事；AI 扩展会消耗额度。

排查：无法扩展时先核对图片来源、比例与分辨率，再检查全局 API 是否已读入、Key 是否为空。接缝错位时检查相邻图块尺寸与重叠设置；仅反复生成而不修正这些设置，可能继续得到同类问题。

## Tile 处理 / RoninTile

整理图块集并绘制瓦片地图。

入口：首页「Tile处理」（站内路径 /tile）。

使用条件：素材处理。这里的编辑、裁切等操作不属于 AI 生图；无需为这些操作切换 API 模式。

准备：准备图块集，明确每块瓦片的宽高以及目标引擎的网格规格。若图集有外边距或格间空隙，先确认切分后每块都是完整图像。

1. 进入编辑器，载入图块集或地图。
2. 按素材设置瓦片尺寸，选择图块在地图上绘制并检查接缝。
3. 保存工程，并通过编辑器导出需要的地图资源。

输出：图块集 / 瓦片地图资源。

注意：确保瓦片大小与游戏引擎一致；图片边缘的空隙会影响拼接。

排查：出现细缝时检查透明空边、图块尺寸与取样位置。先铺一小块包含直边和转角的地图确认规则，再扩大范围；保存工程与导出图片的用途不同，二者都应按需要保留。

## fanAIworld

在实验场景里组合地图、角色与交互。

入口：首页「fanAIworld」。

使用条件：工具 + AI。编辑与 AI 生成分开；调用生成能力时检查 Key 和消耗。

准备：先准备少量地图与角色素材，熟悉页面的移动和编辑方式。要使用 AI 对话时，另外查看对话功能所需配置，不能直接假定生图设置可以通用。

1. 进入场景，先熟悉页面上的移动与编辑提示。
2. 按面板载入或设置场景、角色，检查显示效果。
3. 需要 AI 对话时单独检查该功能的配置，先用小范围场景测试。

输出：场景与交互实验。

注意：AI 对话配置不等于生图 Key 配置；实验功能与正式游戏交付不同。

排查：先分别验证场景显示、角色移动和 AI 对话，定位是哪一部分出问题。缩小测试范围后逐步增加内容，避免同时更换大量素材与交互设置。

## HD2D 模型优化（新版 / 老版）

预览模型并降低模型或贴图的资源负担。

入口：首页底部「HD2D模型优化」→ 新版 / 老版。

使用条件：素材处理。这里的编辑、裁切等操作不属于 AI 生图；无需为这些操作切换 API 模式。

准备：准备 GLB / GLTF 及配套贴图等资源，先保留完整原始模型。明确主要目标是减少面数、降低贴图体积还是调整像素风外观，选择新版或老版后先看原始预览。

1. 选择版本，导入 GLB / GLTF 模型及所需资源。
2. 先预览，再按需要调整减面、贴图压缩、烘焙或像素风处理。
3. 比较轮廓、材质和文件体积，通过对应版本的导出入口保存。

输出：优化后的模型 / 贴图资源。

注意：新版与老版分别保留；参数不能保证通用。务必保留原始模型并在项目中复查材质。

排查：模型缺贴图时先核对导入资源是否齐全。减面后轮廓损坏或材质变化时降低处理强度；导出后在目标项目中重新打开，检查贴图、透明材质和比例。

## 地形插件 / 世界生成器 DLC

了解地形插件及世界生成扩展。

入口：首页右侧「地形插件」；页面内切换「世界生成器 DLC」（站内路径 /terrain-plugin）。

使用条件：独立说明 / 授权。按对应页面的服务或授权说明使用，不包含在代充额度中。

准备：先确认自己需要地形插件还是世界生成器 DLC，阅读展示页的环境要求、功能演示与交付内容。已有项目先记录引擎版本与需要解决的问题。

1. 打开展示页查看插件能力与适用环境。
2. 需要世界生成器时，在页面切换到 DLC，阅读对应说明。
3. 按页面渠道确认授权和使用环境，获得插件后按插件说明在项目中使用。

输出：插件介绍、演示与获取渠道。

注意：这是独立插件服务，代充次数不会自动兑换插件或 DLC 授权。

排查：展示页不是在线地形编辑器。需要直接在浏览器中尝试地形编辑时，可查看像素实验区的 OpenTerrain；插件或 DLC 的授权与使用问题按对应页面渠道确认。

## 建筑生成器

了解参数化建筑与小镇生成插件。

入口：首页左侧「建筑生成器」（站内路径 /building-generator）。

使用条件：独立说明 / 授权。按对应页面的服务或授权说明使用，不包含在代充额度中。

准备：先确定需要单栋建筑还是小镇场景，查看案例是否符合项目风格。核对 Godot 使用环境与插件交付内容，再按展示页提供的方式了解授权。

1. 在展示页查看不同建筑风格与小镇案例。
2. 核对插件适用环境和交付内容，按页面方式咨询授权。
3. 取得插件后在 Godot 中选择预设、调建筑参数，并保存或导出场景。

输出：插件案例、说明与获取渠道。

注意：本站这一页是插件展示，不是输入生图 Key 就能在线生成建筑的工具。

排查：页面没有在线生成按钮并不代表 Key 失效，这一入口用于展示插件。取得插件后先在测试项目尝试预设，核对生成场景的比例与资源，再接入正式项目。
