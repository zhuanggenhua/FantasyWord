# 连续开放地图重构

本轮对象是已有河渡镇生成流程及其可行走预览，权威来源为布局 JSON、MiniFantasy 室内/室外原素材、Tiled 实际保存结果。目标环境是本地 CLI 和离线浏览器，不是 Unity 运行态。

| 职责 | 旧版 | 本轮 |
|---|---|---|
| 空间 | 外部房屋占地，室内未生成 | 地板、墙体、家具都在原世界坐标，不另外放大或传送 |
| 通行 | 整栋矩形阻挡 | 永久墙体和家具阻挡，门洞真实留空 |
| 显示 | 全镇共用屋顶层 | 每栋建筑单独的屋顶和遮挡立面；角色进入本栋区域时揭开，离开恢复 |
| 编辑 | 建筑跨全镇图层 | Tiled 建筑分组拥有全部子层、门洞、室内区域和碰撞，组偏移统一移动 |
| 数据 | 布局输入 → Tiled → 离线包 | 保留此方向；预览与碰撞都从保存后的 Tiled 地图导出 |
| 验收 | 只能走到门口 | 实际移动从外部经过门洞进入室内再退出，验证墙阻挡与遮挡切换 |

保留双桥、市场与住宅街总体布局。过浅的三栋长屋换成有真实进深的房屋组合，门前公共位置尽量保留；石塔仅做地面层，不凭空增加多楼层系统。

文件职责：`generate_town.py` 继续拥有作者与导出入口；`town_preview.py` 负责连续地图的浏览器表现，复用原 Forge 碰撞/寻路运行库，替换不支持动态屋顶的旧预览；`verify_town_preview.mjs` 只负责浏览器验收；`review_town.py` 检查地图和整理交付。没有新增游戏正式运行模块或第二套世界状态。

`town_preview_runtime.js` 只在离线页面存活期间拥有角色的预览状态和揭顶显示；它与 Python 图像打包分开，以便真实键鼠入口和验收共用相同的逐帧移动代码。预览没有提供给验收任意设置角色位置的接口。

不引入场景切换、瞬移入口、网络、NPC业务或大世界流式加载空壳。Kenshi 类比采用用户明确要求的连续空间体验，不把完整游戏玩法推断成本轮范围。
