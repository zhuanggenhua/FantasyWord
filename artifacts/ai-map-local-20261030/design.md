# 本地连续地图拼接工具实验

对象：`scripts/ai-map-experiment/map_stitch.py` 和本目录的新地图；旧小镇及Unity工程不改。
来源：用户提供的FrameRonin技能ZIP；站点可见操作；公开仓库main提交4472253dbf848289a3631bef4bf4d101f2929490中的MapStitch.tsx。
环境：Windows Python/Pillow、当前会话内置生图、原版Tiled CLI；无第三方网站操作依赖，无新增服务密钥。
验收：新生成起始图与真实模型扩图组成同一TMX；旧像素零变化；Tiled原生重读；可从手改TMX继续prepare；过期作业拒绝覆盖。

## 同职责对照及裁决

|职责|FrameRonin公开版本|现有小镇|本轮本地实现|
|---|---|---|---|
|地图作者源|React状态和状态ZIP|TMX图层与建筑组|TMX图像块、偏移、标注|
|扩展准备|四向邻接图块、重叠参考画布|无图像扩图|CLI从当前TMX派生上下文和未知遮罩|
|生成|公开版跳转Gemini；当前站点API生图|确定性原素材铺瓦片|当前会话内置生图，不复制Key|
|保存|状态ZIP、PNG、PSD、Godot|TMX和派生预览|TMX+PNG原资源，job仅为派生快照|
|失败|网页提示|校验报告|尺寸、源变化和未补全均拒绝提交|
|验收|网页检查接缝|地图/导航/浏览器|像素保留、真实接缝与Tiled重读|

只参考邻接上下文和工程保存的通用职责；公开仓库无许可证声明，不复制源码、商标、角色素材、去水印或收费逻辑。独立实现固定已有像素的补全合成，未移植其羽化、PSD或Godot功能。本轮属于离线美术工具，不装配GameCore/Gameplay，不改变Unity生命周期。

新增图为图像块地图，不会自动变成逐瓦片素材；碰撞、真实室内地板和独立屋顶需要后续作者制作。本轮不以烘焙外观图片冒充这些能力。允许Tiled编辑图层偏移和碰撞标注；修改后重新prepare，不能继续提交旧作业覆盖手改。

任务顺序：读源和边界 → CLI拼接 → 新图/邻块生成 → Tiled重读及像素审查 → 交付。
