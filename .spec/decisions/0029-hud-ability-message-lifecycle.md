# 0029-HUD 能力失败提示生命周期 owner 边界

- 日期：2026-07-15
- 状态：已采纳
- 背景：
  - `UIHUDAbilityMessage` 是 HUD 上显示能力释放失败、点击命令失败等短提示的组件。
  - 组件自身用协程推进延迟隐藏和淡出；旧实现已经在启用/禁用时注册和注销失败事件，但提示协程与可见文本状态还没有像其它临时 UI 一样被门禁明确约束。
  - HUD 被隐藏、禁用、销毁或提示内容被快速替换时，旧协程和旧文本状态必须由组件自身清理，不能依赖父级 UI 或动画自然结束。
- 决策：
  - `UIHUDAbilityMessage` 在显示新提示前必须停止旧隐藏协程。
  - 组件禁用或销毁时必须隐藏提示，停止隐藏协程，并清空提示文本、透明度和可见状态。
  - 淡出流程结束时必须直接清理自身协程字段和可见状态，不再从协程内部通过 `Hide()` 反向停止自身协程。
  - UI 静态门禁必须覆盖替换、禁用、销毁和淡出结束的生命周期合同。
- 影响：
  - HUD 隐藏或对象销毁后不会留下旧失败提示协程继续写 UI 状态。
  - 快速连续失败提示会从干净状态重新显示，不会继承上一条提示的文本、透明度或协程句柄。
  - UI 门禁可以阻止该提示组件回退到“只靠自然淡出结束”的隐式生命周期。
- 替代关系：
  - 本决策补强 `0025-临时 UI 动画协程生命周期 owner 边界` 中未单独覆盖的 HUD 能力/命令失败提示。
