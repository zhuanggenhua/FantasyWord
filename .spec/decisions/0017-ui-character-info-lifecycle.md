# 0017-角色信息面板监听生命周期 owner 边界

- 日期：2026-07-15
- 状态：已采纳
- 背景：
  - `CharacterBase` 是角色属性、等级和临时状态效果的真相源，通过属性变化、状态效果变化和升级事件通知外部呈现。
  - `UICharacterInfo` 是固定目标角色信息面板，负责显示指定角色的名字、等级、资源条和状态效果图标。
  - 该面板原先在 `Awake()` 注册目标角色事件，只在 `OnDestroy()` 注销；对象禁用后仍可能响应目标角色变化，并继续持有状态图标实例。
  - 固定目标面板可以早于目标角色或 UI 子引用完全就绪，因此启用期绑定需要具备幂等重试和空目标保护。
- 决策：
  - 固定目标角色信息面板的监听 owner 是组件启用状态，而不是对象创建/销毁状态。
  - `UICharacterInfo` 必须在 `OnEnable` 尝试注册目标角色事件，`Start` 只作为 Unity 时序或目标稍后就绪的重试入口。
  - `UICharacterInfo` 必须在 `OnDisable` 和 `OnDestroy` 退订目标角色事件，并归还当前租用的状态效果图标。
  - 监听注册必须使用幂等标记，避免重复启用、`OnEnable` 与 `Start` 连续执行时重复注册。
  - 资源条和名字等级刷新必须允许目标角色为空，不能因目标尚未绑定而抛出空引用。
- 影响：
  - `UICharacterInfo` 不再在 `Awake()` 注册目标角色事件，`Awake()` 只负责对象池配置和文本格式缓存。
  - 禁用面板会停止继续响应目标角色属性、等级和状态效果变化，并归还所有状态效果图标实例。
  - `scripts/Invoke-UIRuntimeStaticGate.ps1` 已扩展检查角色信息面板的启用/禁用监听生命周期。
- 替代关系：
  - 本决策不改变 `CharacterBase` 作为角色状态真相源。
  - 本决策取代 `UICharacterInfo` 中“Awake 注册、OnDestroy 注销”的隐式生命周期。
