# 0037-水面倒影显式反射来源 owner 边界

- 日期：2026-07-15
- 状态：已采纳
- 背景：
  - `WaterReflectionCaster2D` 负责为角色或场景物体生成水面倒影代理。
  - 旧实现允许运行时在自身子层级内自动寻找 `EquipmentRenderer` 或所有 `SpriteRenderer`。
  - 这种自动收集会让倒影来源由层级形状隐式决定；角色层级、UI 子物体、代理对象或编辑器临时对象变化时，运行时可能绑定错误来源。
- 决策：
  - 水面倒影投射器运行时只接受显式配置的 `EquipmentRenderer` 或 `SpriteRenderer[]`。
  - 缺少正式反射来源时直接报错并禁用该投射器，不再运行时扫描子级猜来源。
  - 编辑器安装器可以在已锁定的目标场景中做确定性查找并写入显式引用，但不得再写回已删除的“子级自动收集”字段。
  - 新增水面倒影运行时静态门禁，阻止运行时自动收集来源和安装器旧字段写入回流。
- 影响：
  - ClickMoveTest 当前场景文件已存在显式树木 `SpriteRenderer` 来源和玩家 `EquipmentRenderer` 来源；本轮不加载、不保存、不重写用户正在编辑的场景。
  - 运行时水面倒影来源更可审计；新对象需要通过场景接线或编辑器工具显式绑定来源。
- 替代关系：
  - 本决策延续项目“正式运行链路不得按层级猜依赖”的硬红线，水面倒影的编辑器安装器只作为一次性接线入口，不作为运行时兜底。
