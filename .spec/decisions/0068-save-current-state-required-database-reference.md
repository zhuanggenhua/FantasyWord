# 0068-当前运行时状态保存必需数据库引用边界

- 日期：2026-07-17
- 状态：已采纳
- 背景：
  - `2DRPGEngine` 的背包、任务日志、装备和任务进度保存链在保存当前运行时状态时直接创建数据库引用；缺数据库登记代表作者数据或运行时状态错误。
  - FantasyWord 读旧档时仍需要容错：坏 GUID、缺失旧资产或迁移失败记录可以在 `LoadDataBlock` 路径里跳过并报错。
  - 但保存当前运行时状态不是坏档输入处理。若保存时继续使用 `TryCreateReference + continue` 或“已跳过”语义，会把已经发生的库存、任务、装备或变形/感染状态静默丢出新存档。
- 决策：
  - `DatabaseRegistry.CreateReference<T>()` 是保存当前状态的必需引用入口；无法从当前数据库登记创建稳定 GUID 时必须抛出可定位异常。
  - `DatabaseRegistry.TryCreateReference<T>()` 保留为需要预检或兼容旧流程的查询入口，但不得在当前状态保存快照方法里配合 `continue` 生成部分存档。
  - 当前状态保存方法必须失败暴露，而不是过滤记录：库存 owner 与物品、任务列表、任务进度、任务子项、装备槽和活跃变形/感染规则都必须能创建稳定数据库引用。
  - `LoadDataBlock` 读坏档路径继续允许跳过无法解析的旧 GUID，并写清现实含义的错误日志；本决策不把读档容错改成全局硬失败。
- 影响：
  - 库存保存遇到无效 owner、空物品、非法数量或未登记物品会中止保存。
  - 任务日志保存遇到无效任务进度、未登记任务或未登记任务子项会中止保存。
  - 已装备槽保存需要有效 `DatabaseRegistry`，装备资产必须能创建稳定数据库引用。
  - 活跃变形/感染规则保存遇到空规则、非法层数或未登记规则会中止保存。
  - 旧档恢复仍可跳过坏记录；这类跳过只属于输入容错，不得复用成输出保存语义。
- 验证：
  - 2026-07-17 `Invoke-FoundationStaticGate.ps1 -AsJson` 通过，`SaveReferenceRequiredMissingPatternCount=0`，`SaveReferenceRequiredDisallowedPatternCount=0`。
  - 2026-07-17 `spec-lint` 通过。
- 替代关系：
  - 补充 0005 的存档稳定身份边界：0005 约束“存什么身份”，本决策约束“保存当前运行时状态时缺身份不能静默降级成部分存档”。
