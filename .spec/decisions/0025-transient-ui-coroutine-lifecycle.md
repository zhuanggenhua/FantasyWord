# 0025-临时 UI 动画协程生命周期 owner 边界

- 日期：2026-07-15
- 状态：已采纳
- 背景：
  - `UITipsItem` 和 `UIEventLogLine` 都是可复用的临时 UI 表现对象，动画由组件自身协程推进。
  - 这些对象会被对象池、父级 UI 或日志容量复用逻辑禁用；旧实现主要依赖动画自然结束来归还或隐藏对象，外部禁用时没有统一清理协程字段和可见文本状态。
  - 对象池复用组件必须把“停止动画”和“清空旧显示状态”收口到组件自身生命周期，不能只依赖调用方按顺序结束动画。
- 决策：
  - 临时 UI 表现组件在替换内容、禁用和销毁时必须停止自身动画协程，并把协程字段置空。
  - 对象禁用时必须清理池化可见状态，例如提示透明度、提示文本或事件日志行文本。
  - UI 静态门禁必须覆盖 `UITipsItem` 和 `UIEventLogLine` 的替换、禁用、销毁协程清理合同。
- 影响：
  - 提示项被对象池回收、父级 UI 隐藏或外部禁用时，不会留下旧协程句柄或旧文本。
  - 事件日志行被容量复用或父级销毁时，旧逐字动画不会继续占用组件状态，下一次显示从干净文本开始。
- 替代关系：
  - 本决策补强 UI 生命周期系列决策中未覆盖的短生命周期、池化 UI 动画对象。
