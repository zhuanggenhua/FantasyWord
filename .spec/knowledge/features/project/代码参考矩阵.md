## 维护规则

- `2026-06-12` 起，`GameCore` 的主口径不再是“少量最小闭包 + 大量后置禁入”，而是“参考源码已整段进入项目目录，后续继续做验证、接线和剔除参考项目专属业务痕迹”。
- `EquipmentSystem` 当前是正式装备/换装表现模块，保留本体、数据资产和独立演示场景；但不得继续使用 `Items` 语义把它伪装成完整物品地基。
- `EquipmentSystem` 不等于 `2DRPGEngine` 的正式 `InventorySystem/Item/Equipment/ItemEffect` 闭包；后者依赖 CharacterBase、Dialogue、Player、Journal、Ability 和 Inventory 通知，正式接入前不得用空 Item/Inventory/SaveSystem 顶替。
- 旧 `GameCore/Foundation`、`Characters`、`World`、`Items/Runtime`、`Combat`、`Presentation` 自造模块链已删除；后续这些能力只能按 `2DRPGEngine` 或其它成熟参考重新建立。
- `EX-GAS` 插件本体仍保留，但没有成熟参考支撑的项目侧第二收口目录和样例定义资产仍已删除；`BroAudio` 则已在 `GameCore/Runtime/Audio` 与 `GameCore/Runtime/Database/Audio` 形成正式收口，后续业务不得再绕过该正式音频闭包直接依赖第三方 API。
- 不能把“有参考编号”理解为“已经完成玩家控制器、背包规则或完整运行时链路接线”。
- 若某个文件被证明只是旧 demo、旧菜单或无引用实验代码，再按“正式链路 / 归档参考 / 真正垃圾”分类处理。
