# 换装测试动作来源表

> 目的：把“动作到底有多少、哪些能进玩家、哪些只能做覆盖、哪些必须排除”固定成可验收表，不再靠口头判断。
> 范围：MiniFantasy 相关目录和 `Assets/GameData/EquipmentSystem/AnimationType` 当前动作库。

## 当前结论

| 分类 | 状态 | 动作 / 素材结论 | 证据 |
|---|---|---|---|
| 人类玩家正式动作 | 已纳入当前动作库 | `Idle / Walk / Wait / Attack / ChargedAttack / Dmg / Jump / SoulDie / SpinDie / Die / Harvest / Chopping / Mining / AnvilWorking / JewelryWorkshopWorking / LaboratoryWorking / WoodworkBenchWorking` | 来自 Dungeon 人类基础动作、Crafting and Professions I 人类采集/制作角色图，当前 `AnimationType` 目录已生成对应动作资产。 |
| Farm 交互动作键 | 已纳入动作库，但不应作为可播放玩家身体动作 | `Butchering / Digging / FillingBucket / Harvesting / Milking / Shearing / SowingSeeds / TillingSoil / Watering` | Farm 原始 `.anim` 在 `Assets/Art/KrishnaPalacio/MINIFANTASY - Farm/Animations/FarmingActions`，真实引用的是 `ActionInProgress(16x16)` 交互图标，不是人物身体帧；当前不能用 `Harvest` 或其它身体动作冒充。 |
| 其它人形种族 | 应走覆盖控制器，不当作新增玩家动作类型 | Dwarf / Elf / Goblin / Halfling / Orc 等基础动作数量与人类基本一致，作为同动作集合的覆盖素材 | `Assets/Art/MINIFANTASY Creatures - Super Low Res 2D Pixel Art by Krishna Palacio/Sprites/Humanoids/*` 和 CP1 Humanoids 覆盖控制器。 |
| 人类变体 | 暂不进入主玩家动作库 | Amazon / Townsfolk 等是人类外观/变体素材，不是新的动作类型 | Creatures Humanoids/Human 子目录。 |
| 动物、怪物、UI、气泡、道具、阴影 | 已明确排除 | Monsters、Beasts、Farm_Animals、Actions/ActionInProgress、Dialogue/Bubble/UI/Icons/Props/Shadows/Gif 等不进入玩家动作库 | 本轮素材扫描统计到非玩家生物、场景/UI/道具/阴影等分类，不能再混入换装动作。 |
