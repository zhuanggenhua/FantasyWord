# 编辑器工具与验证入口

> 本文只记录当前仍然真实存在的 Unity Editor 工具、AI 自动化入口和验证边界。
> 已删除、已归档或已被替换的入口，不再当作正式真相记录。

## 适用范围

- 人工会在 Unity Inspector、正式窗口或正式场景里直接使用的作者入口。
- AI 通过 AIBridge 调用的后台自动化入口。
- 正式审计、只读检查和最小 smoke 入口。

## 当前正式分层

- `Human Authoring`
  - 人类直接编辑正式资产或正式场景时使用。
  - 正式技能的人类入口是 EX-GAS Ability / Timeline / GameplayEffect / Cue 相关编辑面；旧 `AbilitySheet` Inspector 和各 `AbilityExecutionAsset`（已删除） 自定义 Inspector 不再作为技能作者入口。
- `AutomationOnly`
  - AI 或开发自动化使用，不暴露给策划主流程。
  - 当前技能线正式自动化入口是 `Assets/Editor/GameCore/Utils/FormalAbilityAssetValidation.cs` 的 `InspectAllAbilitySheets()`。
- `Internal Temporary`
  - 一次性探针、临时迁移脚本、诊断脚本。
  - 当前不把这类入口写进正式能力制作步骤。

## 第三方编辑器边界

- `Assets/Plugins/GAS/Editor/` 下的 EX-GAS 官方编辑器当前保持上游可编译状态。
- 该可编译状态依赖 `Assets/Plugins/Sirenix` 正式依赖闭包与 `GAS` asmdef 的正式程序集名引用；不得再通过伪 `Odin` 占位脚本或隐藏 define gate 维持“看似可编译”状态。
- 它们属于第三方底层工具；正式技能的正式作者流必须落在 EX-GAS Ability / Timeline / GameplayEffect / Cue，不得再回到 `AbilitySheet` Inspector 或旧执行资产 Inspector。
- 旧 `AbilitySheet` Inspector 与旧执行资产自定义 Inspector 不再作为新技能或正式技能的正式制作步骤；旧执行资产类型已删除，旧 `AbilitySheet` 只保留旧数据读取线索。

## 当前技能线正式真相

- 正式技能正式身份、规则、时序、命中和表现入口：EX-GAS Ability / Timeline / GameplayEffect / Cue。
- 旧技能兼容身份资产入口：`Assets/Scripts/GameCore/Runtime/Database/Abilities/AbilitySheet.cs`
- 旧技能兼容执行资产入口：已删除；不得恢复 `Assets/Scripts/GameCore/Runtime/Database/Abilities/Execution/AbilityExecutionAsset.cs`
- 当前仍保留的旧执行资产族：无。`MeleeAbilityExecutionAsset`、`DashAbilityExecutionAsset`、`ProjectileAbilityExecutionAsset`、`SummoningAbilityExecutionAsset` 均已删除；近战、冲刺、投射物和召唤不得继续通过旧 `ActiveAbilitySheet + AbilityExecutionAsset` 体系表达。
- 当前已存在的旧执行资产对应自定义 Inspector：
  - 无。项目侧旧执行资产自定义 Inspector 已删除，不能恢复成正式能力作者入口。
- 当前唯一正式技能自动化审计入口：
  - `Assets/Editor/GameCore/Utils/FormalAbilityAssetValidation.cs`
  - 它的 `InspectAllAbilitySheets()` 不再检查 `已删除的 AbilitySheet.executionAsset` 引用闭包、运行时类型或 `executionKind`；这些旧执行资产路径已删除。正式技能的正式缺口只能沿 EX-GAS 运行配置、Prefab、Timeline、GameplayEffect 和 Cue 校验。
  - 当前共享校验不再覆盖旧执行资产问题；正式或后续能力不得再用这些旧字段补职责。

## 当前已明确不存在的废弃入口

以下类别不再允许进入活跃流程、活跃文档或正式建议：

- 任何旧 `FormalGas*` 审计或模板脚手架入口
- 任何“准备链路”“修复接线”“技能工作台”式人类菜单

## 当前作者流程边界

- `AbilitySheet` 只允许作为旧存档/旧资产反序列化和旧数据升级线索。
- `AbilityExecutionAsset` 已删除，不得作为旧执行资产兼容层，也不得承载普攻的动作时序、命中窗口、命中框、伤害或表现真相。
- 正式普攻的近战命中和伤害入口是 EX-GAS Timeline / `TaskApplyEffects` / `GameplayEffect`。
- `FormalAbilityAssetValidation.InspectAllAbilitySheets()` 属于开发审计，不属于策划做技能的主步骤。
- 项目侧 `AbilitySheetEditor` 与旧执行资产自定义 Inspector 已删除；不得恢复为正式技能作者入口。
- 近战正式时间轴作者面已裁决为 EX-GAS `AbilityTimelineEditor + XParamTimeline + TaskApplyEffects + TargetCatcher`，项目侧不得再新增同职责第二时间轴。
- 因此当前可以说“技术链路已开始收口”，不能说“正式命中框可视化作者面已完成”。

## 新增工具规则

- 不为了让 AI 调用而新增顶部 `MenuItem`。
- 不把诊断、审计、修补流程包装成策划作者步骤。
- 不在没有参考矩阵和差距闭环前，新造正式命中框 UI、正式复杂法术编辑器或第二套技能真相。
- 若未来新增时间轴或其它可视化编辑面，只能作为同一执行语义的编辑面，不能再造第二套运行时真相。

## 当前推荐验证顺序

- 静态搜索正式入口是否存在、废弃入口是否已清空。
- 只读 Inspector/资产检查。
- `FormalAbilityAssetValidation.InspectAllAbilitySheets()` 是技能职责审计。正式技能不得把 `已删除的 AbilitySheet -> AbilityExecutionAsset` 解释成正式链路；旧执行资产闭包检查已删除。
- 只有静态证据不足时，才升级到 AIBridge 刷新资产与 Console 检查。
