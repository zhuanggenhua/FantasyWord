# 组件库索引

## 适用范围

- 本文索引当前项目可复用组件、资源、管理器和编辑器工具。
- 本文不是功能完成度清单；是否正式启用仍需看对应实现、引用和验证。

## 维护规则

- 新增组件索引前，先确认稳定落点、消费入口、适用边界和验证方式。
- 素材包 demo、旧恢复资产和临时验证脚本不能直接进入本索引的正式组件条目。
- 候选组件可以登记，但必须明确“候选”状态，不能写成已完成验收。
