# Brainstorming（方案收敛）

## 何时使用

- 用户要“参考某项目思想”“整理规范”“设计方案”“怎么做先分析”。
- 目标涉及多个可能结构或职责裁决。
- 用户明确说先不执行。
- 需求可能影响长期规范、架构或工作流。

## 流程

1. 读取当前项目入口和相关文档。
2. 锁定本轮对象、真相来源、目标入口、验收口径。
3. 按职责组织候选方案，不按参考项目巡礼。
4. 给出 2-3 个可选方案及取舍。
5. 标出冲突点和已按当前规范收口的地方。
6. 用户确认“开始执行”后，才转入 `writing-plans`、`task-breakdown` 或直接实施。

## 禁止

- 用户要求“先不执行”时，不得写文件或改配置。
- 不把设计文档更新冒充主任务完成。
- 不把多个参考的同职责代码/数据/流程混成第二套真相源。
