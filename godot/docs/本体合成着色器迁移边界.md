# 本体合成着色器迁移边界

## 对象、来源、入口与判据

对象是原换装 `EquipmentUV` 的“本体合成”阶段，不是整个角色渲染器。
真相源固定为 Unity `31629d53a110dd4c87d4c85e6ad5a387fbafb931` 的
`EquipmentUV.shader` 中 `TransformUV`、`ComputePartIDs`、`ApplyBodyLayers`、
`ApplyHeadLayers` 和 `frag` 的第一阶段。Godot 基线是 `76bed705`。

入口为 `equipment_subset_material.gd.create`，显式创建独立 `ShaderMaterial`。
该入口**尚未接入正式角色场景**。允许绑定的是完整主图及同尺寸的两张完整数据图；
`AtlasTexture` 不能直接作为这些输入。绘制几何的 UV 必须仍指向整张图，不是当前帧归一化 UV。
原装备矩形是左下原点 min/max，绑定器接受 `Rect2` 后明确转成 min/max；
shader 先映射作者区域，再对最终 V 做一次翻转。数据 sampler 无 `source_color`，
强制最近邻、不重复；透明像素的 RGB/部位编号仍参与运算。

## 已迁移范围

- 同一个整图 UV 同时采样主图、Body/Head 数据图。
- B 通道严格小于 `0.025` 的部位判断；Head alpha 仅区分核心，不否决扩展区域。
- 手部与头区域交叠时禁止头层覆盖。
- 北向先头后身，手脚归躯干；南向核心头禁止躯干覆盖，手脚保留颜色层。
- 背包仅南向底图透明处；裤子、上衣、披风覆盖顺序。
- 头盔命中提前返回；否则胡须、面饰、头发择首命中，眼饰、面罩依序覆盖。
- 每层采样 alpha 严格大于 `0.5` 时替换 RGB，独立覆盖率为 1，最后取本体 `charAlpha`。
- 缺图、错误槽类型、非有限/越界/负范围、缺少启用颜色均明确失败；每次材质独立，不遗留另一角色状态。

## 验证层级

`tests/test_equipment_subset_material.gd` 可随 `tests/run.sh` 运行：只证明显式绑定和失败合同，
不证明 headless 后端编译了真实 GPU 着色器。

`tests/rendering/equipment_subset_gpu.gd` 是真正 Godot 图形驱动的辅助入口，
使用动态生成的诊断纹理、两种深度、128 个像素与既有 CPU 合成判据比较。
运行方式：`godot --path godot --rendering-method gl_compatibility --script res://tests/rendering/equipment_subset_gpu.gd`。
它拒绝 headless；测试图不是原版素材，离屏测试也不是最终 GameView 验收图。

本轮云端 `DISPLAY` 为空且本地显示套接字不可用，**未运行 Godot 原生 framebuffer 像素测试**。
另有父线程独立 Mesa EGL / llvmpipe 辅助运算验证：保留 shader 运算、替换 Godot 入口，
对保密原主图、Body/Head 数据图及仅用于诊断的装备色，完成 786432 次像素比较。
这仅支持本体合成运算，不冒充原生 Godot 场景或原装备视觉。私有原图和探针不随代码发布。
