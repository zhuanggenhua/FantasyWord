# 阴影材质桥接边界

## 锁定范围

- 迁移起点：`0c8c8dbf610c2cfd34a524109738e48863fbf18d`。
- Unity 真相源：`31629d53a110dd4c87d4c85e6ad5a387fbafb931` 的 `EquipmentUV.shader` 阴影系统、`GetShadowCasterAlphaAtFrameUV`、最终片元，以及 `EquipmentRenderer.UpdateShadowHeight`。不修改 Unity 分支、原始素材或正式场景。
- 本轮对象：已存在的可选双武器材质变体的阴影阶段；默认本体路径不启用，也不增加采样器。
- 验收层次：原生 Godot 材质绑定合同、全套测试，以及用作者数据验证的原生帧绑定与改编 GLES 数值对照。不是 Unity/Godot 正式场景完整画面对照。

## 原流程到迁移流程

| 原职责 | 当前迁移 |
| --- | --- |
| `UpdateShadowHeight` 按脚部像素写入完整或部分字段 | 既有 CPU 模块 `height_writes` 和 `apply_writes`，本轮不改 |
| 同一材质保留没有被写入的旧字段 | 调用方显式提供合并后的完整 `params`；不从新材质默认值猜历史 |
| 轮廓、阴影使用同一 `_FrameSize` / `_ShadowBaseY` | 本轮复用 `outline_frame_size` / `outline_base_y`，绑定时必须与同帧轮廓输入一致 |
| 原始投影覆盖 | 底图 alpha、裤子/衣服/披风、头盔/头发/胡子/面饰/面罩，以及两槽静态武器；不含背包、眼饰或已画轮廓 |
| 静态武器不区分前后进入阴影 | 原同帧武器姿态采样、严格 alpha 阈值，序列旗标 `< 0.5` 才参与；隐藏身体部分的武器描边旗标不影响投影 |
| 四种阴影模式 | 同样的阈值、闭界、Mode2 非对称矩形、Mode3 十字、Mode0 顺序与重复探针 |
| 轮廓之后判断阴影 | 先完成填充和轮廓，最终 alpha `<= 0.5` 且源开关 `> 0.5` 才判断阴影；阴影色 alpha `> 0` 才整色替换 |
| 最终乘 `i.color` | **尚未迁移**，本轮输出是最终顶点乘色之前的结果 |

## 显式调用合同

1. `create(..., using_weapon_stage = true)` 创建现有可选变体。
2. `apply_weapon_fill` 绑定当前角色帧及两个槽。无武器必须明确两个空槽。
3. `apply_outline` 明确同帧范围、尺寸、基线、两个槽的序列/隐藏旗标。不要描边时三个请求值全零，但仍需绑定这些原始数据。
4. `apply_shadow(material, frame_rect, params, enabled, color)`，其中 `params` 必须完整包含 `frame_size: Vector2`、`mode`、`base_y`、`left_x`、`right_x`、`center_x`。后五项须为有限数值；尺寸有限且为正。

启用成功不等于所有像素都画阴影：`enabled = 0.5`、透明阴影色和完全被本体覆盖的区域仍遵守源片元门限。颜色为既有非 HDR Compatibility 子集的原始数值，不做额外颜色域转换。

任何填充/轮廓刷新都会使此阴影绑定失效，必须重新按顺序绑定。阴影绑定失败也关闭旧阴影，不会把旧帧的影子混进新帧。这是显式桥接的数据有效性约束，**不声称等于 Unity `Refresh` 本身的缓存生命周期**。

## 空脚与未知历史

原函数缺脚只写 `mode = -1`。源片元负数依然进入 Mode0，不是关闭阴影。因此，本桥接接受由已验证前态合并得到的完整负模式状态，不擅自归零或禁用它。

只有 `{"mode": -1}` 不足以确定首次空脚时的帧尺寸和基线，拒绝绑定。若旧尺寸/基线与当前轮廓输入不同，也拒绝：原 Unity 二者是共享字段，不能为了“接近效果”把它们分别适配。本轮未放宽既有轮廓的当前帧像素尺寸合同，因此跨尺寸保留旧 `_FrameSize` 的特殊历史尚未接入，不把它称为原逻辑已完整迁移。

源 `Refresh` 在缺帧数据等情况下可能在调用 `UpdateShadowHeight` 前直接返回；本桥接不推断这种源运行态是否发生。正式 Actor 持续材质生命周期和实际场景帧驱动仍待接入与验收。

## 验证与未完成项

- 原生 Godot 合同测试覆盖默认关闭、13/15 采样器、同帧依赖、四种模式原值、负模式完整历史、缺字段、非有限值、共享尺寸/基线不匹配、刷新失效、开关和颜色阈值的原值传入。
- 70 套 Godot 测试通过，其中新增的材质合同包含 66 项断言。此前 CPU 阴影合同与玩法测试仍通过。
- 私有原始人形 Idle/Walk/Dmg 的 96 帧在原生 Godot 动画与几何节点中绑定同帧阴影：88 帧 Mode0、8 帧 Mode1，无渲染帧缓冲。
- 改编 GLES 对照独立掩码共 191,488 个像素，验证 1,848 次有效替换；同时覆盖原始 Mode2 参数、合成 Mode3、两武器槽、序列排除、描边覆盖优先级和背包排除。默认/可选仍为 13/15 个材质采样器。
- 不新增原始第三方素材，不以测试生成纹理或离屏图冒充正式素材与 GameView 截图。
- 正式 Actor/场景接线、最终顶点颜色相乘、原生 GPU 帧缓冲及 Unity/Godot 同帧完整截图尚未完成；本轮是材质桥接阶段，不是整项迁移交付。
