# 整图帧几何接入边界

## 来源与已实现部分

锁定 Unity 31629d53a110dd4c87d4c85e6ad5a387fbafb931 的 EquipmentRenderer.UpdateCharFrameRect 从当前 Sprite 的实际 texture/rect 绑定整图，而不是按请求动作或标签猜图集列。Sprite.pivot 与 pixelsPerUnit 的坐标含义亦见 TryGetGroundAnchorWorldPosition。角色 Body 原始层级、镜像和切片参数必须由导入证据提供，不能把方向号自动解释成镜像。

equipment_frame_geometry.gd 使用 Polygon2D 显式顶点与 UV：uv 为 AtlasTexture.region 的四个像素角点；Godot Polygon2D 在发送渲染数据时除以整图尺寸。依据为 Godot 官方 scene/2d/polygon_2d.cpp 的 NOTIFICATION_DRAW 分支（https://github.com/godotengine/godot/blob/master/scene/2d/polygon_2d.cpp）。顶点由帧角点减去转换成顶起坐标的 Unity 像素 pivot，再除以源 PPU。明确 flip_h/flip_v 只镜像局部顶点，不重选帧、不改变标签或动画时钟。

## API 与宿主责任

- configure(playback, geometry, material_provider) 返回 bool；只能配置一次。
- geometry 按实际 AtlasTexture 资源身份索引；每项必须明确提供 pivot_bottom: Vector2（Unity 左下起的像素坐标，不是归一化坐标）、pixels_per_unit: 正数、flip_h/flip_v: bool。
- provider(action, label, direction, sample: AtlasTexture) 返回 {ok: true, material: ShaderMaterial}；main_map 必须引用 sample.atlas。调用方据真实动作选择 UV 数据图及装备记录，不能猜失踪资源。
- configure 不主动播放或追溯历史帧，下一次 sample_resolved 才写入原生节点；成功后发 sample_applied，失败清空 polygon/uv/texture/material 并设置 last_error，避免遗留旧帧。
- polygon、uv、texture、material 都是原生显示节点状态，可直接读回验证。
- 宿主应把适配器接在源 Body 对应变换下，并显式隐藏仅用于采样的 Sprite2D，避免双画。适配器不会擅自隐藏它，也不复制其默认像素大小或把父层 scene 偏移误作 Body 偏移。
- 宿主必须明确处理统一的世界坐标比例、排序、颜色、脚底锚点和其他源行为。本脚本不把图块底边当脚底，不自动替换正式 Actor 场景。
- 不支持未证实的 margin、嵌套图集、空/越界 region；这些帧停止绘制。纹理导入后的 region 必须已是 Godot 顶起坐标。
- 当前 adapter 仅负责当前帧的本体几何与整图 UV，不是完整装备系统、完整 Actor 接入或视觉验收。

## 验证

test_equipment_frame_geometry.gd 用合成纹理装配真实 AnimationPlayer / Sprite2D / directional_sprite_playback / equipment_frame_cursor / Polygon2D，经过动画时间推进及切向事件核实非零、稀疏行列，实际资源身份、材质整图、轴点、PPU、显式镜像及失败清空。资源不含原素材或原值表。此测试是原生节点联动验证，不是 GPU 像素比对；仍需正式 Actor 场景接入及 Unity/Godot 同状态截图验收。

私有回归使用源项目实际 Idle、Walk、Dmg 四向精灵库、原 Body/Head 图和 FrameData，将 96 个实际帧送进同一动画、几何和着色器材质绑定。私有导入按原基础人形作者引用及 LFS 校验解析十个头部外观纹理；未把其他外观的肤色表套到人形。实际验证了 Polygon2D 整图、双数据图、非零区域、源 pivot/PPU 和基础人形有发/须但肤色禁用。原素材、清单和私有验证入口均没有加入仓库。这是无头节点联动，不代表正式场景渲染或完整视觉验收。
