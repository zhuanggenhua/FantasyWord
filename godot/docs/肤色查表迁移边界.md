# 肤色查表迁移边界

## 前提与来源

对象为原换装材质的肤色参数与本体后处理子阶段。Unity 真相固定为
`31629d53a110dd4c87d4c85e6ad5a387fbafb931`，Godot 基线为 `4cd2f200`。
源方法为 `EquipmentRenderer.ApplySkinPalette`、`EquipmentUV.ColorApproxEqual`
和本体颜色合成之后、武器采样之前的肤色分支。原 ProjectSettings 的
`m_ActiveColorSpace: 1` 是 Linear。目标入口为独立参数构造及 CPU 参考，
验收是 Godot 原生脚本与独立计算的中间色测试，不是当前场景的图像验收。

## 已迁移规则

- 两数组为空或缺任意数组时关闭启用值且数量归零，不继承先前有效状态。
- 数量为两数组长度与 16 的最小值；实际参数缓冲区固定 16 项。
  未使用槽清零是独立值对象的表示，不能据此改变原渲染器的有效数量语义。
- Linear 模式显式对源色、目标色各转换一次；Gamma 模式保留原数组颜色。
- 仅当前主要像素来源为主体、合成颜色自身 alpha 严格大于 0.5 时查表。
  不用合成后的独立覆盖率来扩大范围，也不以 RGB 猜测是否来自装备。
- RGB 加权亮度系数为 0.299、0.587、0.114，严格大于 0.15。
- 按作者顺序取首个三通道距离均严格小于 1/255 的匹配，非最近色。
- 只替换 RGB，目标数组 alpha 不覆盖本体 alpha。

API 为 `bind_palette(source, target, linear)` 和
`apply(char_color, source_id, palette)`。
参数结果包含 `ok/enabled/count/source/target/linear`；
`source/target` 是 `PackedColorArray`。输入只接受已验证的有限归一化颜色，
不支持 HDR/负值，遇到这些值明确返回错误而不夹取。空配置是合法关闭。
`apply` 只接收本模块成功构造的参数，不作为任意外部字典验证器。

## 测试与未完成范围

合成测试包括非线性中间色与独立 sRGB 数值、两个均在容差内的候选优先级、
同 RGB 但不同来源的头发排除、数量截断、缺数组、alpha/亮度门禁、
所有非主体来源、非法颜色与颜色域误用。
没有发布任何作者 palette 值，未给现有玩家或 NPC 更换外观。

CPU 色值比较不等于 Unity `fixed` / GPU 精度完全一致；极限浮点边界、
真实纹理采样的颜色域、Godot viewport 输出转换、素材导入、材质写入、
正式角色刷新和完整 GameView 对照仍需独立证据。本文件不宣称肤色最终显示、
换装系统或项目整体迁移完成。
