# 轮廓覆盖与层级迁移边界

## 锁定范围

- 问题对象：本体、背包、两槽静态武器的程序描边覆盖及源层优先级。
- 真相来源：Unity `31629d53a110dd4c87d4c85e6ad5a387fbafb931` 的 `EquipmentUV.shader`：`GetLayerPriority`、`GetOutlineAlphaAtFrameUV`、`GetShadowCasterAlphaAtFrameUV`、`GetWeaponOutlineAlphaAtFrameUV_Slot`、`GetBagOutlineAlphaAtFrameUV` 和片元程序描边段。
- 目标入口：独立 CPU 模块 `gameplay/presentation/equipment_outline_coverage.gd`，不改已有填色器、材质、着色器或 Actor。
- 验收：新边界单测和既有 Godot 全套脚本；不代表 Unity GameView/Godot 实际帧缓冲或最终装备场景对齐。

## 逐项语义

| 原逻辑 | 本阶段等价行为 |
| --- | --- |
| 本体覆盖 | MainTex 原 alpha 与裤、衣、披风、头盔、发、须、面饰、面罩命中并集；装备命中贡献 1，不沿用装备分数 alpha。 |
| 原始 UV | 装备采样直接使用 BodyUV/HeadUV 的 RG；不要求部位 B 或核心 A，不复用填色结果。眼饰、手套、鞋不属于此并集。 |
| 图集边界 | 帧内坐标先还原整图 UV，再转为 Godot 顶原点；本体/背包不夹当前帧，整图点采样可以读到相邻帧。武器仍由既有严格帧边界采样器处理。 |
| 武器覆盖 | 仅 `is_sequence < 0.5` 且命中时保留原 alpha；序列武器仍可由已有填色器绘制，但不贡献这里的描边或 Mode0 投影宽度。 |
| 跨槽隐藏 | 任意槽 `hide_outline_on_body > 0.5` 且本体覆盖大于 0.5 时，两个槽都隐藏该点的程序描边。邻居覆盖和中心绘制门禁都检查；投影不受此隐藏开关影响。 |
| 背包 | 只看 BodyUV 原始 RG 和背包命中；不看填色部位或身体前后。源码 `<0.5` 提前退出，所以启用值恰好 0.5 仍可采样。 |
| 优先级 | 本体各来源 50；主手前/后 80/10，副手 70/5；背包北/南 100/0；空或未知为 -1。手前置参数不改变此优先级。 |
| 邻居 | 四个正交方向，步长为帧像素倒数；只有中心位于半像素基线及以上才考虑。轮廓优先级不得低于中心已有填色来源。 |
| 武器邻居 | 被邻居处更高优先级的本体或背包挡住；中心已有任一静态武器轮廓覆盖则两槽都不再扩边。 |
| 手部邻居 | 位于 HeadUV 核心头部或 BodyUV 核心时不扩边；中心填色来源为任一武器时，手部也不扩边。 |
| 输出颜色 | Hit 大于 Extra 大于默认黑；三者均关闭则保留输入。绘制时 alpha 强制为 1，之后才能进行原逻辑的阴影和顶点色阶段。 |

## 调用合同

`coverage(frame_uv_bottom, frame_rect_bottom, sample_sheet, enabled, sample_equip, weapons, sample_weapon)`：

- 局部帧 UV 和帧矩形保持 Unity 底原点，允许邻居 UV 超出局部 0..1。
- `sample_sheet(sheet_uv_top)` 返回 `{main, body, head}` 三个原始 `Color`。图像采样可使用现有 `equipment_uv_sampler.sample_sheet`，不得经 sRGB 转换或填色合成。
- `sample_equip(key, raw_rg)` 返回经对应装备矩形采样后的 `Color`；无命中为透明。启用 key：`pants/cloth/cloak/helmet/hair/beard/face_accessory/mask/bag`。
- 两槽 `weapons` 各含 `is_sequence`、`hide_outline_on_body`、`depth_mode` 数值；缺省表示关闭。`sample_weapon(slot, sheet_uv_top)` 返回命中 `Color` 或 `null`，调用方应连接已有武器帧采样合同。
- 结果包含本体、背包、各槽/合并武器与 Mode0 caster alpha，以及原始 BodyUV/HeadUV。caster 不含背包，也不计入序列武器。

`outline(frame_uv_bottom, frame_size, shadow_base_y, source_id, body_in_front, weapons, sample_coverage)` 返回 `is_outline` 和 `best_priority`。`sample_coverage` 必须调用上述覆盖判据，不能来自最终填色。

`apply_outline` 只执行描边颜色优先级与 alpha，不计算阴影、不乘顶点色。

## 验证与尚未验收

- 新单测覆盖八类独立并集、原始 RG、分数 alpha、严格截止值、真实非零相邻图集格、武器帧边界、序列过滤、跨槽隐藏、全部源层优先级、四邻与半像素基线、手部核心门禁、输出颜色。
- 另有私有作者原图 CPU 对照：Idle/Walk/Dmg 共 96 帧、98,304 像素，2,326 本体描边像素一致。只证明原始数据上的 CPU 判据，不是实际 GameView 或 GPU 验收；原图和私有数据不随本阶段发布。
- 尚未实现：本阶段 CPU 判据接入正式 GPU 共享着色器、模式零投影宽度整体链路、正式 Actor 与装备运行时材质接入、跨引擎完整场景截图验收。
