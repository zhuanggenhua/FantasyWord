# 面部装饰绑定迁移边界

## 锁定范围

原代码版本为 Unity `31629d53a110dd4c87d4c85e6ad5a387fbafb931`，迁移基线为 `76bed705c606787740cea4de4f9f7fd9a8a9013d`。本阶段只迁移面部装饰方向选择、整图纹理引用和作者矩形归一化，不生成素材。

真相链为 `EquipmentRenderer.ApplyAppearance` 的面部装饰分支、`CharacterAppearance.GetFaceAccessorySprite/HasFaceAccessory`、`DirectionalSpriteHelper.GetByFacing` 和 `SpriteUtils.GetUVRect`。目标是 Godot 无头绑定合同；验收为原生脚本组合测试，不是完整画面。

## 实际代码与注释的差异

原数据注释说“只朝南”“不回退”，但实际方法调用通用四向回退，渲染器也没有正面方向门禁。原着色器的面部装饰采样依启用值和 Head UV，而非另行限制正面。因此本迁移不能新增“背向关闭”或“禁止回退”。

- SE 取 SE；SW 缺图回 SE；NE 缺图回 SE。
- NW 依次取 NW、SW、SE；非法枚举取 SE。
- 任一方向可构成有效配置，不要求 SE 必填。
- 方向依 Head 的作者 `spriteFacing`，缺部位时才用当前动画行，不跟随躯干。
- 使用 Sprite 的整张纹理与 `Sprite.rect`，保持底原点；归一化结果是最小值及尺寸，不是最大值。最终 V 翻转由采样器负责，本层不能提前翻转。

## 输入与调用约束

`appearance.face_accessory` 的 `se/sw/ne/nw` 值为已解析的 Sprite 记录，至少包含 `texture: Texture2D` 和 `rect_pixels_bottom: Rect2`。矩形必须来自原作者源；不接受猜测的全图矩形。缺失纹理禁用，缺作者矩形返回明确错误。本模块返回当帧的绑定值，不持有旧纹理，不执行材质写入。正式调用方应沿原 Refresh 先重置启用值，再消费本次绑定结果。

## 证据和未验收项

测试穷举 16 种方向缺失组合与六种合法/非法朝向，检查独立回退期望、纹理身份、非零且非对称矩形；另测空外观、缺纹理和缺矩形。人工纹理只用于参数测试。

尚未连接正式角色刷新入口、实际面饰作者资源解析及 ShaderMaterial 写入；肤色查表、真实 GPU 合成、Unity 原场景与 Godot 完整画面对照均未验收。不能将本阶段描述为外观迁移或项目完成。
