# 肤色着色器迁移边界

## 本轮对象与真相来源

锁定 Unity `31629d53a110dd4c87d4c85e6ad5a387fbafb931` 的
`EquipmentUV.shader` 来源选择及肤色查表阶段。Godot 基线为 `4cd2f200`。
入口是已有本体合成着色器，未连接正式角色，未更改原作者外观或玩法场景。

身体/头部各自保留最后写入层的来源身份，按身体深度确定顶层来源。
没有装备覆盖且底图 alpha 严格大于 0.5 才回退为主体来源。
肤色仅作用于主体来源，装备即使与主体 RGB 完全相同也不会改色。

## 调色规则与显式色域

`skin_palette_enabled` 默认关闭，`skin_color_count` 默认零。
`skin_src_colors[16]` 和 `skin_dst_colors[16]` 是已经线性化的向量数组，
不使用颜色特性再做一次隐式转换。计数限制在 0 到 16。

`skin_color_domain` 默认 0，代表尚未证明，不应用调色。
本阶段只支持 1，代表可见主图与输出都是原始 sRGB 值的非 HDR 兼容模式合同。
查表前仅将主体颜色显式转线性，采用原权重 0.299、0.587、0.114 检查灰值严格大于 0.15，
按数组顺序寻找第一个每通道误差严格小于 1/255 的条目，不选择最近颜色。
只命中时把目标线性 RGB 转回 sRGB。原 alpha 不变，最终覆盖率仍来自本体合成。
未知或其他色域保持原输出，不能猜测是线性视口。
Body/Head 的 UV 与部位编码始终保持原始数值，不参与上述转换。

## 验证层次

`test_equipment_skin_shader_contract.gd` 检查接口及默认关闭，只属无头契约。
`tests/rendering/equipment_skin_gpu.gd` 是原生图形辅助入口：
非线性非对称中间色、两个都在容差内的候选、同 RGB 头发、关闭和未知色域。
需要以 Godot `gl_compatibility` 图形驱动运行；无头明确退出 2，不伪造通过。
诊断纹理不是原版素材，离屏结果不是完整场景截图。

## 未完成

尚未把 palette 正式绑定到实际角色，未验证实际装备作者素材、Unity 与 Godot 完整色彩流程、
真实 Godot framebuffer、线性或 HDR 视口、最终画面。
仍缺武器、描边、阴影等后处理。不得将本轮称为完整换装或完整迁移完成。

材质侧通过 `equipment_subset_material.gd.apply_skin_palette` 显式连接 CPU 作者颜色绑定：仅当调用方确认当前 raw sRGB 合同才启用；未知域、空表或无效配置清除启用值和计数，同一材质不会沿用旧色表。该入口未接等价正式角色刷新。

另以非公开原 authored 外观（五色启用及空表禁用）、原 Idle/Walk/Dmg 主图与 Body/Head 输入做过独立 Mesa EGL 软件验证：393216 次像素对照，其中 1964 次发生替换；额外合成反例在两种深度确认同 RGB 装备不染。仅验证转换出的片元运算，不是 Godot framebuffer 或正式角色截图，不发布原数据和私有探针。
