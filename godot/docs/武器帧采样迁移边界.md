# 武器帧采样迁移边界

以 Unity `31629d53a110dd4c87d4c85e6ad5a387fbafb931` 的 `EquipmentUV.TrySampleWeaponGeneric` 为真相源。输入为当前实际完整角色图的顶原点 UV、作者角色帧矩形与装备矩形（底原点、最小值和尺寸）、原手锚与虚拟手、cos/sin、镜像和启用状态。从整图转帧底原点，减角色手锚，先旋转再横镜像，再加虚拟手；帧或武器局部超域不采样。按装备切片映射，并且仅在进入顶原点图像令 V 反向。点采样后要求 alpha 严格大于 0.5，保留完整 alpha 引入后续覆盖。矩形和输入非有限时明确拒绝。

与本轮独立绑定和遮盖合同衔接：调用方用 `equipment_weapon_pose.gd` 提供 static/sequence 的实际输入，将原武器 `Sprite.rect` 归一化；采样成功才进入 `equipment_weapon_fill.gd` 的前后合成。采样器本身不决定动作、武器分配、角色 look 或源导入颜色域。

合成用例包含非轴心手点、非零图集坐标、90°、先旋转后镜像及像素透明度边界。另以源项目真实圆盾原资产 SE/SW 对应 LFS 内容、原人形帧及作者副手锚在私有环境做 88 帧 / 90112 个像素探针（704 个命中）与独立源方程参照吻合。其余 8 帧无副手锚，未混入有效输入。私有测试不是声明角色正式装备圆盾，原素材与数据不发布。

目前只是 CPU 绑定、坐标及填充参考。两槽材质与本体/武器/阴影/描边流水线、原序列实际游标、实际角色场景、Godot 帧缓冲和 Unity 对照仍需验证。
