# ClickMoveTest 原静态测试面板

`--source-preview --control-panel` 在现有场景预览上启用原诊断区。需要
`FORMAL_PANEL_SILVER` 和 `FORMAL_PANEL_CJK` 指向来源 31629d53 的
`Assets/Fonts/Silver.ttf` 和 `NotoSansSC-VF.ttf`；不把原字节提交到仓库。
找不到指定原字体直接拒绝，不用系统字体假装还原。其余启动方式不变。

面板根据原对象 251610374/375/377 和两个 TMP 文本对象设置 28 像素
顶/左留白、1120×520 高度缩放、原背景色与标题 52、正文 40/行距 6。
父层和两个标签均不拦截点击。面板只观察实际受控目标、当前模式和移动指令；
在已经存在的点击入口记录屏幕点和投影，等原一轮倒计时后再显示实际路线。
切换 Tab 不由面板调用；主角仍作为镜头回退时不冒充当前输入目标。

验收包括实际鼠标事件穿过面板、面板外点击、模式切换、延迟读回、中文正文
可见像素和窗口尺寸变化；另从完整原图预览启动。正文和标题仍由 Godot
排版、原生加粗，未宣称 TMP 动态排版、SDF 采样或 Unity 像素完全一致。
