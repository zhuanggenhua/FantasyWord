# ClickMoveTest 战斗技能栏

## 来源与范围

Unity 锁定在 `31629d53a110dd4c87d4c85e6ad5a387fbafb931`。原场景的 User Interface 实例 25059 挂载 HUD 实例 5956719457626161344；同一屏幕 Canvas 的参考尺寸 1920×1080，按高度缩放。HUD 的 Ability Bar（6484177053198568707）距底 25、高 100；中间对齐、间距 16，子项 96×96。Group 不拦射线，已占槽的整张背景拦射线，不向角色下达移动，也不通过鼠标释放技能。没有显示来源的空槽整项禁用，不占间距。

战斗 HUD 与暂停技能页不同：HUD 只排已装备项，原逻辑索引不变；菜单保留五个可编辑格。HUD 读取正式 PlayerOwner 所持有的同一装备快照，并监听变化，失去控制目标解绑，重新获得角色时刷新。初始化允许主角色回退，后续切换事件直接采用真实角色或空值。暂停只叠暗幕、切换输入，不藏起 HUD。

槽位继承原 Generic/Ability 的 tiled 背景、sliced 框、48×48 图标。复用许可范围内同一私有 atlas 和攻击图，不进 Git。实际初始两项均无冷却；喷火保留启用 Image 的空 Sprite 白块，与无来源的空槽不同。锁定入口按钮提示管理器默认关闭，不添加默认手柄图。没有扩张到非零冷却、技能失败提示、其他角色或整套游戏 HUD，也没有声称 Unity 截图逐像素通过。
