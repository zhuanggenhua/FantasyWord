# ClickMoveTest 战斗技能栏

## 来源与范围

Unity 锁定在 `31629d53a110dd4c87d4c85e6ad5a387fbafb931`。原场景的 User Interface 实例 25059 挂载 HUD 实例 5956719457626161344；同一屏幕 Canvas 的参考尺寸 1920×1080，按高度缩放。HUD 的 Ability Bar（6484177053198568707）距底 25、高 100；中间对齐、间距 16，子项 96×96。Group 不拦射线，已占槽的整张背景拦射线，不向角色下达移动，也不通过鼠标释放技能。没有显示来源的空槽整项禁用，不占间距。

战斗 HUD 与暂停技能页不同：HUD 只排已装备项，原逻辑索引不变；菜单保留五个可编辑格。HUD 读取正式 PlayerOwner 所持有的同一装备快照，并监听变化，失去控制目标解绑，重新获得角色时刷新。初始化允许主角色回退，后续切换事件直接采用真实角色或空值。暂停只叠暗幕、切换输入，不藏起 HUD。

槽位继承原 Generic/Ability 的 tiled 背景、sliced 框、48×48 图标。复用许可范围内同一私有 atlas 和攻击图，不进 Git。实际初始两项均无冷却；喷火保留启用 Image 的空 Sprite 白块，与无来源的空槽不同。锁定入口按钮提示管理器默认关闭，不添加默认手柄图。没有扩张到非零冷却数值、其他角色或整套游戏 HUD，也没有声称 Unity 截图逐像素通过。

## 原失败提示

Ability Message 单独占用原全宽 y=899 至 931，不参与槽位间距。只在显示时拦指针；HUD 挡住的世界点击没有命令，自然没有失败提示。空槽的实际按键触发“这个槽位没有装备技能。”，该原因的松键保持静默。独立技能失败与本地命令失败从两个实际回调进入，通用 AbilityRejected 不覆盖已显示的专用原因。

提示白色、32 点中部对齐。拉丁字形来自私有原 RPGSystem SDF atlas；本段原中文使用已核哈希的 Silver.ttf 及其原前进宽度，无系统字形兜底。不宣称动态的 Godot 中文像素与 Unity TMP 相同。新提示替换旧提示；1.5 秒缩放时间等待、0.5 秒不缩放淡出，Pause 只停住等待，已开始的淡出不受影响。默认两项技能不提供真实冷却或法力失败场景，这几个原因只通过独立事件契约核对，并非自然战斗实测。
