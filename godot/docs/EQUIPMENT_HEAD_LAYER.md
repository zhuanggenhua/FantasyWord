# 头部像素合成判据

按锁定 Unity `31629d5` 的 `EquipmentUV.ApplyHeadLayers` 迁移独立 CPU 判据：非头区域或手与头重叠时直接跳过；覆盖资格不要求是核心头部。开启的头盔采样成功后立即返回，否则胡须、面饰、头发按顺序取第一个有效的，再允许眼饰覆盖，最后面罩覆盖。各纹理 alpha 严格大于 0.5 才成功；写入 RGB、保留底色 alpha，独立头层覆盖置一。来源编号保留给后续描边和层间判定。不做 alpha 混合。

此模块只迁移合成规则；调用者提供已按真实图集映射采样的颜色。它未接生产材质，也未实现身体层、描边、阴影、武器或其他 Shader 路径。本地测试仅覆盖顺序、门禁、像素和 alpha 语义，不证明画面对照。

`equipment_character_layers.gd` 将此规则接回源角色层顺序：身体朝前先头后身，否则相反。南向核心头部会阻止躯干覆盖，手脚保留各自着色；北向手脚参与躯干装备。南向背包只在底图 alpha 不超过截止值才尝试。裤、服装、斗篷按顺序覆盖，眼色直接取已绑定值。最后独立计算头身覆盖和主要来源，保留下一步皮肤查表、武器、描边、阴影需要的输入；不声称包含这些阶段。
