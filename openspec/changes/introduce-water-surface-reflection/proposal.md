# Proposal: introduce-water-surface-reflection

## Why

当前移动测试场景已经有动画水，后续开放世界还会把水默认作为可进入、可游泳区域。水面倒影如果只按常见教程做成“反射相机翻转画面 + 水面 Shader 采样”，很容易和本项目的实际需求冲突：

- 水是动画 RuleTile，不是静态平面。
- 项目是俯视角像素游戏，倒影需要像素感、轻量、可裁剪，而不是写实水面反射。
- 移动端需要控制额外渲染成本，不能每块水域或每条河流单独创建反射相机。
- 水默认可游泳，游泳动画已经自己处理“只显示上半身”的视觉，不应再由倒影方案重复处理身体遮罩。
- 水面倒影需要按距离和对象状态分级：近处有明显倒影，中距离弱化，远处只保留水面动画或暗色波动。

因此需要独立 change，把水面倒影定义为“水域表现系统”的一部分，而不是孤立 Shader 特效。该 change 只提出方案、规范和实施任务，不在提案阶段修改代码、材质、场景或渲染配置。

## Project Tier

长期项目。水面倒影会影响地图 Tilemap、URP 2D 渲染、角色表现、游泳状态、移动端性能和后续开放世界区域加载，不能作为单个测试场景的临时效果脚本处理。

## Current State Lock

- **问题对象**：动画水 Tilemap、可游泳水域判断、倒影捕获、倒影合成材质、移动测试场景中的水层。
- **真相来源**：`ClickMoveTest` 场景现有水层、`LakeGrass.asset` 动画规则瓦片、当前 URP 2D Renderer 配置、Unity 6 URP 2D Renderer 文档、用户提供的 B 站水面倒影教程。
- **目标入口**：水面视觉仍由现有动画水 Tilemap 承担；水域进入/游泳判断由正式水域状态入口承担；倒影由一套共享低分辨率捕获和水材质合成承担。
- **验收口径**：在当前移动测试场景中，角色可以进入水域并保持游泳动画逻辑，岸边树木/建筑/岸上角色在近水处有像素风倒影，远处倒影自动弱化或关闭，移动端成本可控。

## Scope

本 change 包含：

1. 定义水默认可游泳的开放世界规则，不把水 Tilemap 继续当作整块实体阻挡。
2. 定义水域状态入口，统一服务游泳、涟漪、倒影淡出和后续水体交互。
3. 保留现有动画水 RuleTile 作者流程，不复制第二套手工水面 Tilemap。
4. 使用一张共享低分辨率倒影纹理捕获可倒影对象。
5. 定义近、中、远三个倒影质量层级，并允许最低档完全关闭倒影。
6. 定义水材质合成动画水、倒影纹理、水像素 Mask 和轻微像素扰动。
7. 定义游泳中玩家倒影规则：不使用普通站立完整倒影，默认关闭或只保留极弱上半身波动影。
8. 约束 xBRZ、Camera Sorting Layer Texture、额外相机和 URP 2D Renderer Feature 的职责边界。

## Out Of Scope

- 游泳动画本身、上半身显示、身体遮罩和游泳动作状态机。
- 真实 3D 水面、法线海浪、折射深度、物理浮力和潜水系统。
- 每个水域独立反射相机。
- 河流流速模拟、船只、漂浮物、完整水体生态。
- 多层地形桥洞/桥面导航；如水域与桥洞相交，按对应地形 change 另行处理。
- 端到端截图或视觉素材出图；实施阶段再按用户要求验收。

## Distance-Based Reflection Policy

首批按水面到主相机视口中心或玩家附近的有效距离分级，具体阈值可在实施阶段调参：

| 等级 | 适用区域 | 倒影表现 | 成本策略 |
| --- | --- | --- | --- |
| 近景 | 玩家附近、屏幕主要交互区域 | 明显像素倒影，带轻微水波扰动和透明度衰减 | 使用共享 RT 采样，允许较高 alpha |
| 中景 | 屏幕内但非交互焦点 | 倒影变暗、变短、扰动更强，细节弱化 | 降低采样强度，避免额外局部效果 |
| 远景 | 远离玩家或小面积水面 | 不显示清晰倒影，只保留动画水自身明暗变化 | 可完全跳过倒影采样 |
| 低端设备 | 移动端低质量档 | 关闭动态倒影，保留动画水和涟漪 | 不分配或低频更新倒影 RT |

## Sequencing

1. 先做 V0：一台共享正交反射相机、一张低分辨率 RT、一个水面合成材质，验证像素倒影气质。
2. 再接入水域状态入口：水默认可游泳，进入水域后游泳动画由现有角色表现负责。
3. 再做对象过滤和游泳中玩家倒影淡出：岸上对象可倒影，游泳中的玩家不做完整倒影。
4. 再升级为正式 URP 2D 渲染入口：避免 xBRZ 对倒影 RT 产生错误重采样。
5. 最后做质量档和性能验收：近中远分级、低端关闭、移动端帧成本记录。

## Acceptance Direction

- 动画水 Tilemap 继续按现有 RuleTile 动画显示，不需要复制第二套视觉水。
- 大多数水域默认可游泳，水面本身不再整体阻挡角色。
- 岸线、石头、悬崖和地图边界仍可作为独立障碍阻挡移动。
- 岸上角色、树木和建筑在近景水面有可读的像素风倒影。
- 游泳中的玩家不出现完整站立倒影。
- 中远景水面倒影自然弱化，不因全屏水体导致移动端明显过载。
- 低质量档可以关闭动态倒影而不破坏水面动画和游泳表现。
- 倒影捕获不会把 UI、整张地表或无关 Tilemap 渲染进反射纹理。
