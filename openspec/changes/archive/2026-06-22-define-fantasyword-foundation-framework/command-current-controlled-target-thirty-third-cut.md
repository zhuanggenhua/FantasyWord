# 第三十三刀：命令默认目标跟随当前受控角色

## 背景

能力菜单、快捷栏、角色面板、装备 UI 和玩家输入目标已逐步收口到当前受控角色，但一组脚本/交互命令在没有显式 actor 时仍回退到长期玩家主角。

这不符合当前游戏目标：Kenshi / 博德之门 / ToME4 式多角色、变形、感染和临时控制切换下，命令默认目标应是当前正在行动的角色，而不是固定主角。

## 本刀变更

- `AddExperience` 默认目标改为当前受控 Hero。
- 能力授予/移除、法力、效果施加、治疗/伤害、复活和移动命令默认目标改为当前受控角色。
- `ExecuteCommandList` 的临时动作禁用/恢复改为作用于命令上下文 actor 或当前受控角色。
- `IsAbilityUnlocked` 改为检查当前受控 Hero。
- `Invoke-FoundationStaticGate.ps1` 新增命令目标回归门禁，防止这些命令重新硬绑长期玩家主角。

## 边界

- 不修改存档、地图穿越、任务等级等长期玩家档案语义。
- 不实现控制组、多选、队友自动选择优先级、远程访客、网络 ownership 或 FishNet。
- 不重命名旧命令类。旧类名里的 `Player` 暂时保留为参考兼容命名，但执行语义已收口到当前受控角色。
