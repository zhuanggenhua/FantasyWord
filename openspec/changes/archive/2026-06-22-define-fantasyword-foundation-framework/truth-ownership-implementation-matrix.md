## 判定口径

- `保留`：当前入口就是唯一正式真相，允许继续使用，但不得无边界扩张。
- `替换`：当前实现不再承担该职责，由胜出方直接成为正式入口。
- `融合`：不同层级由不同来源胜出，但公开入口只能保留一套。
- `暂不动`：现在实施会制造第二真相、第二生命周期或业务竖切负担，只登记边界和门禁。
