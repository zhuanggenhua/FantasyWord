# 卡牌自走棋模式专项矩阵

> 本文件只定义游戏内卡牌自走棋模式的框架归属。
> 当前不实现卡牌、棋盘、单位、奖励、UI 或具体规则。

## 当前结论

| 项 | 结论 |
| --- | --- |
| 产品归属 | 游戏的一部分，不是外部小游戏或独立工程 |
| 长期数据 | 可依赖玩家档案、卡牌收藏、卡组、背包奖励和存档 |
| 单局数据 | 必须由模式运行时拥有，不能挂到开放世界当前地图或当前角色 |
| 输入 | 需要模式输入上下文，不能复用开放世界移动输入真相 |
| 当前动作 | 只登记模式运行时边界，不新增运行时代码 |

## 数据分层

| 数据 | 所有者 | 可依赖 | 禁止依赖 |
| --- | --- | --- | --- |
| 卡牌收藏 | 玩家长期档案或卡牌收藏数据块 | 存档、奖励、背包或商店结算 | 单局棋盘对象 |
| 卡组 | 玩家长期档案或模式配置数据 | 卡牌收藏、存档、UI 编辑入口 | 当前开放世界地图 |
| 单局棋盘 | 卡牌模式运行时宿主 | 卡组快照、随机种子、规则配置 | `MapSystem`、开放世界碰撞、当前控制角色 |
| 单局单位状态 | 卡牌模式运行时宿主 | 卡牌定义、临时 Buff、战斗规则 | `CharacterBase.currentStats`，除非明确做成共享战斗规则 |
| 回合/自动战斗推进 | 卡牌模式运行时宿主 | 模式时间轴、规则配置 | `GameManager.XxxSystem` 快捷入口 |
| 奖励结算 | GameCore 长期系统 | 背包、货币、任务、存档 | 单局状态直接改文件 |

## 运行时候选

| 候选 | 优点 | 风险 | 当前判断 |
| --- | --- | --- | --- |
| `ModeRuntime` 或同级模式宿主 | 清楚隔离开放世界、卡牌、剧情、主菜单等模式 | 需要先定义模式生命周期 | 推荐方向，但当前不建空类 |
| `GameManager.CardSystem` | 调用方便 | 把局部模式状态伪装成项目全局系统 | 禁止 |
| `MapSystem` 子状态 | 可复用场景加载 | 地图真相会吸收模式规则 | 禁止 |
| UI 面板持有牌局 | 做起来快 | UI 拥有规则和状态，后续不可维护 | 禁止 |
| 独立 Unity Scene 脚本 | 原型快 | 容易脱离玩家档案和存档真相 | 只能作为经批准的临时试做，不能默认进入正式框架 |

## 与现有系统关系

| 系统 | 允许关系 | 禁止关系 |
| --- | --- | --- |
| `SaveSystem` | 保存卡牌收藏、卡组、战绩、奖励领取状态 | 单局棋盘每帧状态直接成为全局存档真相 |
| `InventorySystem` | 奖励物品、货币、卡牌包可进入长期数据 | 具体卡牌定义背包系统形状 |
| `InputSystem` | 进入卡牌模式后切换模式输入上下文 | 复用开放世界移动输入驱动牌局 |
| `UISystem` | 展示牌局、卡组和奖励 | UI 拥有牌局推进和胜负规则 |
| 已删除的旧通知中心 / `EventKit` | 新事件用 GameCore 强类型事件 + Yoki `EventKit.Type` | 重新引入 `NotificationSystem.cardXxx` 或任何等价旧通知入口 |
| `Stats/GAS` | 若卡牌单位共享 RPG 属性规则，必须先裁决属性真相 | 单局单位同时使用卡牌数值和角色 `currentStats` |

## 禁止项

| 禁止项 | 理由 |
| --- | --- |
| 新增 `GameManager.CardSystem` 或 `GameManager.CardModeSystem` | 模式状态不是项目级全局系统 |
| 创建空 `World/Card/Mode` 框架目录占位 | 当前不实现业务，空框架会变成技术债 |
| 让单局牌局依赖开放世界当前地图、当前控制角色或移动输入 | 生命周期不同，会产生隐藏耦合 |
| 为卡牌模式单独建存档文件系统 | 长期数据应进入正式存档聚合 |
| 先迁具体卡牌或具体 UI | 具体内容会增加地基重构负担 |

## 后续动作

| 顺序 | 动作 |
| --- | --- |
| 1 | 保持当前无运行时代码状态，禁止 `GameManager` 快捷入口扩张 |
| 2 | 进入卡牌模式设计前，先定义模式宿主生命周期：进入、暂停、退出、结算、失败回滚 |
| 3 | 定义长期数据块：卡牌收藏、卡组、奖励和战绩 |
| 4 | 定义单局状态：棋盘、单位、回合、随机种子和模式输入 |
| 5 | 复用当前 `UIKit` 菜单运行时裁决，为牌局 UI 只新增模式面板，不重新引入第二套菜单入口 |
