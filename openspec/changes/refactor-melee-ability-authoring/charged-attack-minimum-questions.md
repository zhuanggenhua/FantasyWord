# Charged Attack Minimum Questions

## 目的

这份问题清单只覆盖“会改变近战代码结构和资产模型的最小必要信息”。

它不讨论：

- 具体数值平衡
- 具体技能内容
- 具体动画资源名
- 具体特效/音效素材

当前不回答这些问题，就不应继续把蓄力攻击硬写进项目侧旧执行资产或临时字段，否则会再次变成 AI 自己发明正式模型。

## 当前已锁定的前提

- 基础攻击与背刺已经走 EX-GAS Ability Code / Timeline / GameplayEffect；普攻不再保留旧 `MeleeAttackAbilitySheet` 身份根，基础攻击运行不再存在 `MeleeAbilityExecutionAsset`（已删除）
- 背刺当前是“同一近战执行模型上的额外条件 + 额外结果”
- 当前没有蓄力攻击的正式数据模型、正式流程或正式运行时代码

## 最小必要问题

### 1. 蓄力释放是“必须松手才生效”，还是“按住到阈值后自动释放”？

为什么必须先确认：

- 这会直接决定是否需要“按住态”运行时状态
- 会决定 `FormalAbilityInputGateSettings` / 近战时序段是否要支持“等待释放”
- 会影响输入和状态机结构

### 2. 蓄力结果是“同一命中窗口参数放大”，还是“切换到另一套命中窗口/命中结果”？

为什么必须先确认：

- 这会决定 EX-GAS Timeline / GameplayEffect 里是只需要“蓄力倍率”，还是要支持“多阶段结果分支”
- 会影响正式时间轴数据结构是单段参数增强，还是分支式时序段

### 3. 蓄力攻击是“只有满蓄一档”，还是“至少有轻蓄 / 满蓄多档”？

为什么必须先确认：

- 这会决定正式 EX-GAS 数据是否只需要一个阈值，还是需要多档阈值表
- 会影响未来时间轴窗口的数据表达方式

### 4. 未达阈值提前松手时，是“退回普通攻击”，还是“打出弱蓄力”，还是“直接取消”？

为什么必须先确认：

- 这会决定蓄力段结束后的运行时分支
- 会影响基础攻击和蓄力攻击是否真的是同一执行模型上的阶段切换

### 5. 蓄力期间是否允许角色转向 / 移动 / 被打断？

为什么必须先确认：

- 这会直接决定蓄力段需要哪些正式时序控制字段
- 会影响 `AbilityPermissionSettings`、正式输入门控与 EX-GAS Timeline 之间的边界

### 6. 蓄力反馈是“沿用同一份近战 feedbacks，只多几个蓄力节点”，还是“蓄力额外反馈单独一组”？

为什么必须先确认：

- 这会决定 EX-GAS Cue / `GameplayFeedbackSet` 是否要扩成“普通挥砍 + 蓄力开始 + 蓄满 + 释放”分组
- 会影响表现挂点的数据结构

## 当前不需要问的问题

这些问题当前不会改变代码结构，因此不是本轮最小必要问题：

- 蓄力攻击具体叫啥名字
- 蓄力倍率到底是 1.5 还是 2.0
- 具体用哪条动画
- 具体音效/特效素材名
- 是否加屏幕震动

## 当前建议的确认顺序

只要先回答下面 3 个，就足够开始设计蓄力段正式模型草案：

1. 释放方式：松手释放 / 自动释放
2. 结果形态：参数放大 / 切换另一套命中窗口与结果
3. 档位数：单档 / 多档
