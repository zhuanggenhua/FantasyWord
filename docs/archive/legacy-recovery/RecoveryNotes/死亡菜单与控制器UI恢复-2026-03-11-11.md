## 本轮完成

### 菜单与死亡界面

- 新增 `AUIMenu`，给同类菜单一个统一的 `BasePanel + IStackable` 基类
- 新增 `UIDeath`

  - 可返回主菜单

### 控制器提示与导航光标

- 新增 `UIControllerButton`
- 新增 `UIControllerButtonManager`
  - 根据当前控制器类型切换图标库
  - 支持 `Interact` / `FireAbility1-5` / `OpenGameMenu` / `Submit` / `Cancel`
- 新增 `UINavigationTarget`
  - 复用当前工程 `AudioSystem` 与 `GameConfig` 的导航/指针/提交音效
- 新增 `UINavigationCursorTarget`
- 新增 `UINavigationCursor`
  - 跟随 `EventSystem.currentSelectedGameObject`
- 新增 `UIPlayerControllerFeedback`
  - 基于 `PlayerController.interactionTarget` 在目标上方显示交互提示

### 宿主适配

- 扩展 `PlayerController`
  - 增加 `interactionTarget`
  - 增加附近交互目标检索
  - 增加 NPC / `CommandTrigger` 交互触发
  - 增加暂停菜单请求发布
- 扩展 `UISystem`
  - 消费 `MenuRequestEvents.GameMenuRequested`
  - 消费 `MenuRequestEvents.DeathScreenRequested`
  - 消费 `PlayerEvents.HeroKilled`
  - 统一分发 `ui.cancel` 到当前栈顶面板
- 扩展 `GameConfig`
  - 补回 `interactionLayer`
- 调整 `UIMgr`
  - 保留栈顶选中态兜底
  - 不再直接承担项目层输入分发

## 本轮踩坑

- 首轮 `unity-batch-compile-20260311-13.log` 失败，原因有两层：
  - `Assets/Plugins/ZFrame/RunTime/Manager/UI/UIMgr.cs` 所在的 `ZFrame.dll` 不能直接引用项目层 `GameManager`
  - 同一插件程序集也没有可直接用的 `UnityEngine.InputSystem` 引用
- 最终修正：
  - 把项目层输入分发逻辑移到 `Assets/Scripts/Game/Systems/UISystem.cs`
  - `UIMgr` 只保留不跨程序集的 UI 栈行为
