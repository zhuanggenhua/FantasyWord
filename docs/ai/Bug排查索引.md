# Bug 排查索引

> 本索引只放可复用的故障排查经验和案例入口，避免把 `开发与验收规范.md` 膨胀成 bug 流水账。

## 使用规则

- 通用验收门槛、自动化边界和完成性口径仍放 `开发与验收规范.md`。
- 具体 bug 案例、症状、误判路径、证据链和验收记录放 `docs/ai/bugs/`。
- 每条 bug 记录必须写清：症状、误判风险、真实根因、必查项、验收口径和关联文件。
- 不把“降噪、止血、绕过、日志消失”写成根因修复；案例必须回到原始位点验收。
