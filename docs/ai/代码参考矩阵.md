# 代码参考矩阵

> 本文维护 `FantasyWord` 项目侧 C# 文件的来源、参考编号和落点。它不是当前功能完成度清单。

## 适用范围

- 覆盖 `Assets/Scripts`、`Assets/Editor`、`Assets/Tests` 下的项目侧 C# 文件。
- 新增、保留或重写项目侧 C# 前，先补本文或对应专项参考记录。
- 外部插件本体不在本矩阵逐文件登记；项目侧直接承载正式职责的代码需要登记。

## 维护规则

- `EquipmentSystem` 当前不是临时垃圾；它是装备/换装框架候选，后续迁移前要继续审查引用、命名空间、菜单入口和资源闭包。
- 不能把“有参考编号”理解为“已完成正式验收”。
- 若后续决定把 `EquipmentSystem` 正式纳入框架，应补齐更细的逐文件矩阵、测试入口和运行时落点。
- 若某个文件被证明只是旧 demo、旧菜单或无引用实验代码，再按“正式链路 / 归档参考 / 真正垃圾”分类处理。
