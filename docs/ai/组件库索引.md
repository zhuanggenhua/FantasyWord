# 组件库索引

## 适用范围

- 本文索引当前项目可复用组件、资源、管理器和编辑器工具。
- 本文不是功能完成度清单；是否正式启用仍需看对应实现、引用和验证。

## 当前组件候选

- 组件/资源：装备与换装表现系统
- 当前落点：`Assets/Scripts/Items/EquipmentSystem`、`Assets/GameData/EquipmentSystem`
- 适用场景：角色装备层、MiniFantasy 类像素角色外观、动画帧与装备表现数据。
- 当前状态：候选保留，已从旧路径重整到 `Items/EquipmentSystem`；不是临时垃圾。
- 验证入口：迁移完成后通过静态引用检查、Unity 导入、编译和定向场景/Prefab 检查确认。

- 组件/资源：MiniFantasy UV 资源链
- 当前落点：`Assets/ThirdParty/MiniFantasyUV`、`docs/archive/mini-fantasy-uv-evidence`
- 适用场景：追溯 MiniFantasy 角色换装、UV 数据、GUID 来源和资源闭包。
- 当前状态：资源来源与证据保留；证据文件不是框架本体，也不是要删除的垃圾。
- 验证入口：通过 GUID 映射、资源引用和装备系统数据闭包检查确认。

- 组件/资源：MiniFantasy 素材包
- 当前落点：`Assets/Art/MINIFANTASY - Crafting and Professions I`、`Assets/Art/MINIFANTASY Creatures - Super Low Res 2D Pixel Art by Krishna Palacio`
- 适用场景：俯视角角色、怪物、采集、制作、道具和开放世界表现素材。
- 当前状态：素材主体保留；demo 场景已归档到 `docs/archive/minifantasy-demo-assets`，不作为正式导入入口。
- 验证入口：后续按具体角色、采集物或怪物 Prefab 建立正式引用闭包。

- 组件/资源：AIBridge 自动化
- 当前落点：`Packages/com.aibridge.unity`、`.codex/skills/aibridge`
- 适用场景：Unity Editor 后台自动化、资源刷新、测试、Console 和静态/低层验证。
- 当前状态：已替换旧 UnityMCP 作为正式自动化目标。
- 验证入口：迁移完成后再使用唯一正常 Unity Editor + AIBridge 验证。

## 维护规则

- 新增组件索引前，先确认稳定落点、消费入口、适用边界和验证方式。
- 素材包 demo、旧恢复资产和临时验证脚本不能直接进入本索引的正式组件条目。
- 候选组件可以登记，但必须明确“候选”状态，不能写成已完成验收。
