# 组件库索引模板

## 适用范围

- 本文是新增 `组件库索引.md` 条目时使用的模板。
- 本文不描述当前组件完成度，也不把模板字段当成正式现态。

## 使用规则

- 新增可复用组件、资源、管理器、编辑器工具或项目侧服务时，先按本文模板补齐条目。
- 如果只是临时探针、一次性修复脚本或旧恢复资产，不进入组件库索引。
- 候选组件可以登记，但必须明确候选状态、验证入口和不适用边界。

## 条目模板

```md
- 组件/资源：
- 当前项目落点：
- 消费入口：
- 适用场景：
- 不适用边界：
- 关键依赖：
- 当前状态：
- 验证方式：
```

## 推荐优先建立索引

- 俯视角玩家输入与控制入口。
- 角色表现、动画和装备层入口。
- 物品、背包、装备和制作入口。
- 采集点、世界交互和地图对象入口。
- EX-GAS 技能、状态效果和战斗能力入口。
- 音频播放入口和 BroAudio 配置入口。
- 存档、配置和资源加载入口。
- AIBridge 自动化和编辑器工具入口。
