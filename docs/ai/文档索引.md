# 文档索引

> 本索引用于回答两个问题：现在有哪些正式文档；遇到某类任务时先读哪几篇。

## 适用范围

- `docs/ai` 负责长期规则、导航、工具入口、参考矩阵和历史入口。
- 当前迁移阶段的临时结论不能写进旧 `task_plan.md`、`findings.md`、`progress.md`；这些文件只作为旧恢复历史参考。
- 当前没有 OpenSpec 目录时，先以本索引和 `AGENTS.md` 作为 AI 入口；后续若引入 OpenSpec，再把阶段任务迁入 `openspec/changes/`。

## 任务触发建议

- 看新游戏目标、旧用户故事是否继承、联机是否纳入当前目标：读 `项目定位与迁移边界.md`。
- 看文件应该放哪、哪些旧目录只是历史遗留：读 `项目目录与入口.md`。
- 改 `Packages/manifest.json`、ProjectSettings、Input System、URP、场景或 Prefab：读 `Unity工程通用规范.md`。
- 定义俯视角运行时目录、GameCore、输入、世界、表现和联机预留边界：读 `框架与运行时入口.md`。
- 接入 EX-GAS、设计技能/状态/战斗边界：读 `Unity架构与GAS规范.md`。
- 替换 UnityMCP、接入 AIBridge、迁移第三方插件：读 `参考源映射.md` 和 `Unity工程通用规范.md`。
- 做 Unity Editor 自动化、测试、Console、截图：读 `AIBridge常用命令.md`。
- 做 bug 修复、验证或清理旧资产：读 `开发与验收规范.md`。
- 新增或整理 `Assets/Editor` 工具：读 `编辑器工具与验证入口.md`。
- 新增或改 Unity Test Framework 测试：读 `TDD测试规范.md`。
- 新增、保留或重写项目侧 C#：读 `代码参考矩阵.md`。
- 新增或沉淀可复用组件、资源、管理器、工具入口：读 `组件库索引.md`。
- 处理俯视角角色素材、MiniFantasy 角色动画、装备换装素材：读 `角色素材处理工作流.md`。
- 整理像素素材、Sprite、动画、装备表现：读 `素材与表现规范.md`。
- 整理测试场景、样例场景、恢复场景：读 `测试场景与AI复用入口.md`。

## 历史归档原则

- 旧 `FantasyWorld` 恢复记录、乱码调查、换装测试主线和 MiniFantasy UV 验证只保留为历史证据。
- 如果历史记录仍有参考价值，应迁入 `docs/archive/` 或在新文档中以“历史参考”明确标注。
- 不能把历史文档中的 `Next:`、`进行中`、`Phase`、`待继续` 直接当成当前会话任务。
