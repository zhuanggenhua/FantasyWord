# 参考与复用来源映射

## 适用范围

- 本文定义哪些来源可以参考、复用、复制、导入或安装，以及触发哪些门禁。
- 参考不是灵感；当来源被用来决定正式职责、命名、API、Inspector、序列化、运行逻辑、资产组织或验收口径时，必须形成参考记录。

## 当前来源总览

- `dark-corridor` Unity 项目：可直接复用 AI 规范分层、AIBridge 接入、工程治理、参考矩阵方法和 Unity 自动化边界；不复用横版平台动作产品结论。
- 旧 `FantasyWorld` / 当前 `FantasyWord` 历史恢复记录：只作为事实线索，不继承旧用户故事和旧任务阶段。
- MiniFantasy 类像素资源：可作为俯视角像素开放世界素材来源；正式使用前需确认授权、资源路径、导入设置和 `.meta` 稳定性。
- Unity 官方 API 与官方包：URP 2D、Input System、2D Animation、Tilemap、Test Framework 等。
- AIBridge：作为编辑器自动化与验证工具，不作为玩法运行时依赖。

## 依赖核验触发条件

当任务只是让外部工具或包在本项目可用时，走依赖核验，记录：

- 包名
- 来源 URL
- 版本或 commit
- UPM path
- 依赖项
- 旧入口迁移范围
- 本项目调用方式

当前包与插件迁移项：

- 旧项：`com.ivanmurzak.unity.mcp`，来源 OpenUPM，旧 UnityMCP。
- 旧项：`cn.lys.aibridge`，来源 `https://github.com/wang-er-s/AIBridge.git`。
- 新项：`com.aibridge.unity`，来源 `https://github.com/aiseog3121/unity-ai-bridge.git?path=/Packages/com.aibridge.unity`，当前落点 `Packages/com.aibridge.unity`，本项目调用方式为 Unity Editor 文件 IPC 自动化。
- 目标：统一到当前 AIBridge 工作流，旧 UnityMCP 不再作为正式入口。
- `com.exhard.exgas`：EX-GAS 1.1.8，来源 `https://github.com/No78Vino/gameplay-ability-system-for-unity.git?path=Assets/GAS`，当前落点 `Assets/Plugins/GAS`，依赖 NaughtyAttributes，作为后续技能/状态/战斗能力系统候选。
- `JKFrame`：来源参考项目 `dark-corridor/Assets/Plugins/JKFrame`，当前落点 `Assets/Plugins/JKFrame`，依赖 NaughtyAttributes 与 Input System；是否进入正式运行时框架需按俯视角开放世界需求另行审查。
- `com.dbrizov.naughtyattributes`：NaughtyAttributes 2.1.5，来源 `https://github.com/dbrizov/NaughtyAttributes` / 用户 fork，当前落点 `Assets/Plugins/NaughtyAttributes`，用于 Inspector 中文化和编辑器可读性。
- `com.cysharp.unitask`：UniTask 2.5.10，来源 Cysharp UniTask，当前落点 `Assets/Plugins/UniTask`，用于项目侧长期异步流程候选。
- `com.ami.broaudio`：BroAudio 3.1.3，来源 `https://github.com/man572142/Bro_Audio.git?path=/Assets/BroAudio#3.1.3`，当前通过 `Packages/manifest.json` 接入，不硬拷插件本体。
- `com.unity.addressables`：Unity 官方 Addressables 包，当前通过 `Packages/manifest.json` 接入，用于满足 JKFrame `ResSystem_Addressable` 和 UniTask Addressables 扩展的编译依赖；正式资源加载方案仍待项目侧决定。

## 参考矩阵触发条件

当外部来源决定正式功能设计或验收时，至少记录：

- 参考项名称
- 来源路径或 URL
- 已读文件
- 证据等级
- 关键能力清单
- 当前 Unity 落点
- 差距
- 验证入口
- 未覆盖风险

## 当前明确不照搬

- 不照搬 `dark-corridor` 的横版 CorgiEngine 玩家控制器和横版相机。
- 不照搬旧 `FantasyWorld` 的旧用户故事、旧单场景换装目标和历史任务阶段。
- 不把 UnityMCP 安装器作为正式编辑器工具继续保留。
